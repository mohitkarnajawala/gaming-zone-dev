# Number Tapping — Game Guide

## Quick summary
Number Tapping is a fast reaction game. A target number is shown, and the player must find and tap the matching number in a shuffled **3×3 grid** before time runs out. The available time becomes shorter as the player progresses, so the challenge is to stay quick and accurate.

## How to play
1. Start the Number Tapping game.
2. Look at the target number shown on the screen.
3. Find the matching number in the shuffled 3x3 grid.
4. Tap the matching number as quickly as possible before time expires.
5. Continue finding the target numbers as the game progresses.
6. Pay attention to the timer because the available time decreases as progress increases.

## Game Rules
- A target number is displayed for the player to find.
- The number grid contains shuffled numbers arranged in a 3x3 layout.
- The player must select the number matching the displayed target.
- The available time becomes shorter as progress increases.
- Quick and accurate taps help the player progress.

## Tips and Strategies
- Read the target number carefully before tapping.
- Scan the grid systematically instead of searching randomly.
- Keep your eyes focused on the target and the grid.
- Avoid tapping a number before confirming that it matches.
- As the timer gets shorter, make decisions quickly.
- Practice regularly to improve recognition speed.
