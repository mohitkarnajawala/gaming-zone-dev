# Number Tapping — Game Guide

## Quick summary
Number Tapping is a fast reaction game. A target number is shown, and the player must find and tap the matching number in a shuffled **3×3 grid** before time runs out. The available time becomes shorter as the player progresses, so the challenge is to stay quick and accurate.

## How to play
1. Look at the target number displayed on the screen.
2. Find the same number in the shuffled 3×3 grid.
3. Tap the matching number before the timer expires.
4. Keep going as the time window gets shorter.

## Tips
- Read the target number first, then scan the grid.
- Scan systematically instead of jumping your eyes randomly.
- Confirm the number before tapping; a fast wrong tap can cost you.
- Practise to improve your visual scanning and reaction speed.
